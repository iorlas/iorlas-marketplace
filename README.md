# iorlas-marketplace

Curated Claude Code skills by iorlas.

## Installation

```bash
claude plugin marketplace add iorlas/iorlas-marketplace
```

## Available Plugins

| Plugin | Description | Install |
|--------|-------------|---------|
| [iorlas-brainstorm](https://github.com/iorlas/iorlas-brainstorm) | Adaptive brainstorming & decision coaching. Detects your decision-making pattern and applies targeted techniques. | `claude plugin install iorlas-brainstorm@iorlas-marketplace` |
| [iorlas-learn](https://github.com/iorlas/iorlas-learn) | AI learning feedback loop: capture lessons (`/learn`) and load relevant lessons at session start (`/recall`). | `claude plugin install iorlas-learn@iorlas-marketplace` |
| [iorlas-task-loop](https://github.com/iorlas/iorlas-task-loop) | Autonomous task loop over a bd (beads) backlog with a live dashboard of tasks, sessions and workers. Pairs with iorlas-delegate. | `claude plugin install iorlas-task-loop@iorlas-marketplace` |
| [iorlas-perform](https://github.com/iorlas/iorlas-perform) | `/perform`: scenario to multi-voice Russian audio scene with timeline, local on Apple Silicon (Fish Drama 3 / S2 Pro). | `claude plugin install iorlas-perform@iorlas-marketplace` |
